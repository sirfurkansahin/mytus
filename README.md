# MY TUS

Kişisel TUS çalışma süreci takibi ve planlama uygulaması (**Web Mobil / PWA**, Flutter). Soru bankası değildir; tıbbi içerik üretmez.

**Canlı Adres:** https://sirfurkansahin.github.io/mytus/

## Temel Özellikler
- **Bugün & Takvim:** Konu yerleştirme, R0–R4 aralıklı tekrar motoru, gecikme kayması ve telafi planı.
- **Dersler:** Klasik Branşlar veya SpeeTUS Sarmal Sistem müfredat seçimi, kişisel konu notları (notlar özeldir, paylaşılmaz).
- **Kütüphane:** Kitap ve bölüm ilerleme takibi, fotoğraflı/etiketli bölüm notları, takvim köprüsü.
- **Misafir Modu & Bulut Eşitleme:** Hesap açmadan yerel kullanım veya e-posta/şifre ile bulut yedekleme (Firebase Spark).
- **Çalışma Grubu:** Davet koduyla 2–10 kişilik çalışma grubu, haftalık puan tablosu ve ortak hedef takibi.

## Geliştirme ve Yayın
- Kod analizi, testler ve Flutter Web derlemesi GitHub Actions (`.github/workflows/deploy-web.yml`) üzerinden otomatik çalışır.
- Canlı yayın yalnızca `main` dalından GitHub Pages üzerine yapılır.

## Proje Belgeleri
