# Tasarim taslaklari (Faz 3, onaylandi)

Bu klasor, kullanicinin onayladigi MY TUS Surum 1 ekran taslaklarinin kopyasidir (9 ekran, 390x844 telefon boyutu).
Dosyalar sade HTML'dir; tarayicida acilirsa goruntulenebilir (yazi tipi Google Fonts'tan gelir). Veriler ORNEKTIR.

Ekranlar: Karsilama, Main (Bugun), Dersler, Konu, Takvim, FTAyar, FTSayac, Ilerleme, Ayarlar.

Tasarim dili: ana renk mor (#5B3EC8), acik yuzey #FBFAFE, metin #1D1A2B, tekrar vurgusu kehribar (#B45309), klinik dersler yesil (#0F766E), sayac ekrani koyu mor (#241757). Yazi tipi: Figtree. Alt menu: Bugun, Dersler, Takvim, F.T. time. Ilerleme ve Ayarlar "Bugun" ekraninin sag ustunden acilir. Tema telefonun ayarina uyar (taslaklar acik temada cizildi).
